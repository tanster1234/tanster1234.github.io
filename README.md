# tanster1234.github.io

Personal site of Tanmay Bhanushali — Data Scientist & AI Engineer.

- **Branches:** `source` holds this Astro project; `master` holds the built site that GitHub Pages serves.
- **Stack:** Astro (static), a canvas scroll-film player, Lenis, GSAP (ScrollTrigger, SplitText), anime.js, three.js.
- **Film:** generated with Higgsfield (Nano Banana 2 keyframes, Seedance 2.0 clips), graded and assembled into `public/film/`.

```bash
npm install
npm run dev        # local development
npm run deploy     # build, then publish dist/ to the master branch
```
